ÉCONOMIA AI — Version 0.1, prototype gratuit et autonome.

Contenu : index.html, app.js, manifest.webmanifest, sw.js, icon.svg.

Pour tester : ouvrir index.html dans un navigateur (certaines fonctions PWA requièrent HTTPS).
Pour installer sur iPhone : publier ces cinq fichiers sur un hébergeur statique HTTPS, ouvrir l'adresse dans Safari puis Partager > Sur l'écran d'accueil.
Exemple : GitHub Pages avec un dépôt public NE CONTENANT AUCUNE DONNÉE BANCAIRE.

Attention : prototype sans authentification, sans chiffrement applicatif, sans synchronisation familiale et sans véritable modèle IA. Les données importées restent dans localStorage du navigateur ; n'y importer des relevés sensibles qu'après une revue de sécurité et un stockage adapté. Le détecteur de fraude n'est qu'un outil indicatif. Le comparateur de prix en direct, la connexion bancaire et le filtrage automatique des appels ne sont pas intégrés.
